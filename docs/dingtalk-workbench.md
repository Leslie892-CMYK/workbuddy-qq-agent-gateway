# 钉钉工作台（本机版）

这一路径不需要钉钉组织授权，也不改动 QQ 网关。运行 `npm run start:dingtalk` 后，打开终端打印的本机地址。地址中的令牌用于访问工作台，请勿转发。工作台仅监听 `127.0.0.1`，课表、消息摘录、批准记录保存在 `runtime/dingtalk-workbench.json`，不会提交到 Git。

## 当前可用

- 导入 XLSX 的“全部”工作表，手动对应周次、日期、时间、校区、课程、班级、教师、地点等列；筛选一周/校区后生成群通知和逐位教师草稿。
- 可填写无需个人通知的教师，工作台会在本机记住该设置。重新导入课表会列出变动，并使原有批准失效。批准动作只记录审核结果，不向钉钉发送。
- 下载每周一准备通知、每周二核对已读的重复 `.ics` 日历提醒，再由用户导入日历。
- 下载授课名单 PNG，供用户核对后作为通知附件使用；可记录每位老师次日的已读、未读或已人工联系状态。
- 在钉钉桌面打开一个聊天，输入准确聊天名后读取当前窗口可见文字。读取通过本机辅助功能 API；首次使用需在 macOS“隐私与安全性 → 辅助功能”中授权启动工作台的应用。聊天标题不一致时拒绝读取。
- 工作台保持打开时可选择每 15 秒读取当前聊天；切换到其他聊天后，标题校验会停止该次收集。批准通知后可一键复制正文，再由用户在钉钉核对收件人并手动发送。
- 每个聊天本地保存独立上下文，可单独启用，能主动关联其他会话的上下文，并用 WorkBuddy 处理已收集的文字。关联是双向可见的：私聊关联群后，私聊内容可能影响群的回答。WorkBuddy 需按项目原有方式配置 `modules/workbuddy-agent` 的 Python 环境。
- 每个会话可按权限保存本地文件和图片表情，文本文件的前 1 万字可用于助手回答；常用 Unicode 表情可插入提问框。课表批次可调用 WorkBuddy 做只读复核。

## 当前边界

钉钉桌面自动发送、文件/表情发送、已读回执自动抓取和智能家居动作尚未接入。会话中的通知、日历和智能家居开关已提供并落盘，但这些开关不会启用尚未实现的动作；QQ 端原有能力保持原样。读取仅覆盖当前屏幕可见的文字，不代表钉钉完整历史；发送前应核对课表、收件人和通知正文。

课表可能存在合并单元格、日期公式或图片格式的字段。导入后必须审查预览；缺少班级或地点时工作台会提示。下载的授课名单图片是重新绘制的表格，应与原课表截图人工核对。
